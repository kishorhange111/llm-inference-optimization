# Security Policy

## Supported versions

Only the latest commit on the default branch is supported.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.
Report them privately via GitHub's [private vulnerability reporting](../../security/advisories/new)
(Security tab -> "Report a vulnerability"). You can expect an initial response within 7 days.

Never commit API keys or credentials; use a local `.env` file (git-ignored) instead.
